# Настройка

Файл — `config.yaml` рядом с `RU-ATC.exe` (или в корне исходников). Установщик создаёт его из `config.example.yaml`. Комментарии в образце можно править. Пути с обратной косой в кавычках лучше писать через прямой слэш: `"D:/X-Plane 12"`.

После правки программу нужно перезапустить.

## Позывной и запасной план

```yaml
callsign:
  spoken: Аэрофлот
  number: "1234"
flight_plan:
  departure: UUEE
  arrival: ULLI
  cruise_fl: 330
```

Если FMC Zibo отдал план, он важнее этого блока. Без плана диспетчер работает по `flight_plan`. Таблица `airlines` переводит код из номера рейса (`AFL1234` → «Аэрофлот 1234»).

## Связь с X-Plane

```yaml
sim:
  source: webapi      # webapi | udp | mock
  host: localhost
  webapi_port: 8086
  webapi_version: auto
  use_zibo_datarefs: true
```

`host` — компьютер, где запущен X-Plane. Для второго ПК в сети укажите его IP. Порт должен совпадать с симулятором, по умолчанию 8086.

Вы «на связи» с органом, на частоту которого настроен **активный COM1**. На чужой частоте ответа нет, в окне будет подсказка. Отключить проверку: `atc.strict_frequency: false`.

## Строгость readback

`atc.readback_strictness`

* **lenient** (так и записано установщиком, и так же, если ключа в старом файле нет). Закрывают указание: «подтверждаю», «подтверждаю приём», «понял», «принял», «выполняю», «вас понял», «так точно», «роджер», «уилко». Можно с позывным: «пятьсот первый» — это 501. Мелкие ошибки распознавания вроде «подтвреждаю», «шереметев», «делились» прощаются. Если в той же фразе названа неверная ВПП, эшелон, код или частота, диспетчер поправит. Одну и ту же просьбу повторить он задаёт не больше двух раз, затем сам называет значения и идёт дальше.
* **strict**. Нужно повторить сами значения. Голое «понял» указание не закроет.

Рядом: `atc.readback_timeout_s` (по умолчанию 20 секунд, затем «подтвердите приём») и `atc.confirm_correct_readback` («правильно» после верного повтора).

## Окно и горячие клавиши

```yaml
ui:
  always_on_top: true
  topmost_reassert_s: 2.0
  start_compact: false
  compact_alpha: 0.85
  compact_geometry: "560x180-20+40"
  full_geometry: "1100x680"
  compact_borderless: true
  hotkey_toggle: "ctrl+shift+a"
  hotkey_compact: "ctrl+shift+z"
  focus_on_show: false
```

* `always_on_top` держит окно над другими. Раз в `topmost_reassert_s` секунд программа поднимает его снова, не забирая фокус у X-Plane. В эксклюзивном полноэкранном режиме это не работает, нужен оконный или безрамочный режим симулятора. Переключатель «Поверх всех» есть и в окне.
* Компактная панель: кнопка «Компактно», ключ запуска `--compact` или `start_compact: true`. На ней фаза, орган, разрешение, код, **последние 5 реплик** (диспетчер бирюзовым, пилот жёлтым, новые снизу) и индикатор тангенты. Панель без рамки перетаскивается мышью. Двойной щелчок или «⤢» возвращает полный вид, «—» прячет окно.
* `compact_geometry: "560x180-20+40"` — ширина, высота, 20 пикселей от правого края и 40 от верха.
* `hotkey_toggle` показывает и прячет окно, в том числе свёрнутое. `hotkey_compact` переключает компактный и полный вид. Пустая строка клавишу выключает. Сочетание не должно быть занято в X-Plane.
* `focus_on_show: false` после показа возвращает фокус симулятору. `true` оставляет фокус в окне, чтобы сразу печатать фразу.

## Папка X-Plane и навигация

```yaml
flight_plan_import:
  xplane_path: "D:/X-Plane 12"   # установщик пишет сам
navdata:
  provider: xplane               # xplane | navigraph | off
  xplane_path: ""                # пусто = путь из flight_plan_import
  cache_dir: ""
  corridor_km: 50
  rebuild: false
```

`provider: navigraph` ничего не скачивает: подписки в программе нет. `off` оставляет только учебные yaml.

Пустая строка в одном ключе берёт другой. Оба пустые — автопоиск. Свой `navdata.xplane_path` важнее для частот и схем, свой `flight_plan_import.xplane_path` важнее для папки `Output/FMS plans`. Как устроен кэш, какие файлы читаются и что смотреть в журнале — в [[Навигационные данные|навигационных данных]].

## Папка планов FMS

```yaml
flight_plan_import:
  source: auto          # auto | fmc | fms | config
  xplane_path: ""       # например "D:/X-Plane 12"
  fms_max_age_h: 12
  fmc_side: 1           # 1 — CDU командира, 2 — второго пилота
  poll_s: 2.0
  callsign_from_fmc: true
```

`xplane_path` — папка установки X-Plane 12. Планы ищутся в `Output/FMS plans` внутри неё. Пустая строка включает автопоиск: `%LOCALAPPDATA%\x-plane_install_12.txt` (в том числе если файл в UTF-16), типичные пути (`C:/X-Plane 12`, `D:/X-Plane 12`, Steam) и, если задан, `navdata.xplane_path`. Если папка не найдена, в журнал пишется, что именно проверялось: нет пути, это не корень X-Plane, или корень есть, но каталога планов ещё нет. Что делать дальше — в [[Устранение неполадок|устранении неполадок]]. Как план попадает диспетчеру — в [[План полёта|плане полёта]].

## Тангента и звук

```yaml
voice:
  enabled: true
  ptt_key: "caps lock"          # или "right ctrl", "f12"
  ptt_joystick: null            # {device: 0, button: 5}
  input_device: null            # null, номер или часть имени: "acer"
  output_device: null
  host_api: null                # WASAPI | MME | DirectSound
  radio_effect: true
  radio_noise: 0.015
```

Удерживайте клавишу, говорите, отпустите. В окне есть кнопка «Тангента» и поле текста — ими удобно проверить фразеологию без микрофона.

`input_device: null` — устройство записи Windows по умолчанию. Если гарнитур несколько, укажите кусок имени. Одно устройство Windows показывает отдельно для каждого звукового API; `host_api: MME` обычно самый совместимый.

Список устройств из исходников: `python tools/mictest.py --list`.
