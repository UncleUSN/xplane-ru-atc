# Модели речи

Веса не лежат в git и не вшиты в setup. Установщик и программа качают их с сайтов авторов.

В мастере две группы радиокнопок. В группе можно выбрать только один пункт.

## Распознавание (Vosk)

Список совпадает с моделями, на которые рассчитана программа. Адреса — со страницы <https://alphacephei.com/vosk/models>, обе под Apache 2.0.

| Кнопка | Папка | Размер | Когда брать |
| --- | --- | --- | --- |
| Лёгкая `vosk-model-small-ru-0.22` (по умолчанию) | `models/vosk-model-small-ru-0.22` | 45 МБ, около 300 МБ памяти | обычный компьютер, быстрый ответ. Числа иногда путает, повторяйте их по цифрам |
| Большая `vosk-model-ru-0.42` | `models/vosk-model-ru-0.42` | 1,8 ГБ, несколько ГБ памяти | если лёгкая плохо понимает гарнитуру. На странице Vosk большие модели в общем описании требуют вплоть до 16 ГБ |

Скачивание идёт в мастере, с <https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip> или `.../vosk-model-ru-0.42.zip`. Если загрузка сорвалась, при первом вылете программа качает ту же официальную ссылку сама и пишет прогресс в `logs\`.

В `config.yaml` путь такой:

```yaml
voice:
  stt_engine: vosk
  vosk_model_path: models/vosk-model-small-ru-0.22
  vosk_grammar: false
```

`vosk_grammar: true` ограничивает словарь фразеологией и работает только у лёгкой модели (в имени папки есть `small`). На проверочном наборе свободный режим был точнее, поэтому по умолчанию грамматика выключена.

Старые модели `vosk-model-ru-0.22` и `vosk-model-ru-0.10` на той же странице тоже Apache 2.0, но в мастер не входят. Их можно положить в `models\` вручную и прописать путь, если папка содержит `am\` и `conf\`.

## Синтез (Silero v4_ru)

Программа умеет одну модель синтеза: **v4_ru**. Радиокнопка выбирает голос этой модели, не другую модель.

| Голос | Пол | Портрет |
| --- | --- | --- |
| aidar (по умолчанию) | мужской | мужской |
| eugene | мужской | мужской |
| baya | женский | женский |
| kseniya | женский | женский |
| xenia | женский | женский |

Установщик записывает выбранный голос и в `voice.silero_speaker`, и во все органы `voice.unit_voices`, чтобы по радио звучал именно он. В образце `config.example.yaml` у органов разные голоса — так можно сделать потом, поправив файл. Пример смешанного эфира:

```yaml
voice:
  tts_engine: silero
  silero_speaker: aidar
  unit_voices:
    delivery: baya
    ground: eugene
    tower: xenia
    radar: aidar
    approach: aidar
    control: eugene
```

Пол портрета берётся из голоса органа: женские — baya, kseniya, xenia; мужские — aidar, eugene.

Сама модель при установке не качается. При первом запуске `torch.hub` берёт код с <https://github.com/snakers4/silero-models> и вес с <https://models.silero.ai/models/tts/ru/v4_ru.pt> (около 40 МБ). В установленной копии кеш — `models\torch`. Пока файла нет, в окне будет «Загрузка синтеза речи…» и нужен интернет.

Лицензия этих голосов — CC BY-NC-SA 4.0, для продажи продукта они не подходят. Подробности и какие голоса можно рассматривать вместо них — в `THIRD_PARTY_LICENSES.md`.

## Если Silero не загрузилась

Программа пробует дальше голос Windows (pyttsx3, нужен русский голос вроде Microsoft Irina: Параметры → Время и язык → Речь) и только потом остаётся текстом. В config это `tts_engine: silero`. Поставить `pyttsx3` можно сразу, тогда Silero не нужна.

Онлайн-голоса edge-tts в установщик не входят.
