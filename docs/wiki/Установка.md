# Установка

Пользователю не нужно ставить Python. Установщик `RU-ATC-0.3.2-beta-setup.exe` собирается в GitHub Actions (или локально на Windows, см. [[Сборка установщика|Сборку установщика]]) и кладётся артефактом сборки. В репозитории готового exe нет.

## Мастер

1. Запустите setup. Права администратора не нужны: папка по умолчанию — `%LOCALAPPDATA%\RU ATC`. Можно выбрать другую, например `D:\xplane-ru-atc`, если в неё есть запись.
2. Прочитайте страницу с предупреждением про модели и лицензию Silero.
3. Укажите папку программы.
4. На странице **«Папка X-Plane 12»** укажите каталог симулятора (там, где `X-Plane.exe`). Если программа нашла установку сама — по `%LOCALAPPDATA%\x-plane_install_12.txt` или по типичным путям `C:\X-Plane 12`, `D:\X-Plane 12`, Steam — путь уже подставлен. Кнопка обзора открывает выбор папки. Нет внутри `Resources\default data` — мастер предупредит и спросит, записывать ли путь всё равно. Пустую папку тоже можно пропустить: тогда путь ищется при запуске.
5. На странице **«Модели речи»** две группы радиокнопок. В каждой группе отмечается ровно один пункт.
   * Распознавание: лёгкая `vosk-model-small-ru-0.22` (по умолчанию) или большая `vosk-model-ru-0.42`.
   * Синтез: один голос Silero `v4_ru` — aidar (по умолчанию), baya, kseniya, xenia или eugene.
6. Нажмите «Установить». Выбранный архив Vosk скачается с <https://alphacephei.com/vosk/models> и распакуется в `models\` внутри папки программы. Веса в setup не вшиты.
7. Если `config.yaml` ещё нет, установщик записывает его из `config.example.yaml`: путь к модели и выбранный голос у всех органов. Уже существующий `config.yaml` целиком не перезаписывается (модель и голос остаются). Папка X-Plane пишется в оба ключа `xplane_path` и в новый, и в старый файл.
8. Ярлык — в меню «Пуск». Ярлык на рабочем столе — по галочке.

Тихая установка (`/SILENT`) берёт варианты по умолчанию: лёгкая Vosk и голос aidar.

Если архив Vosk не скачался, установка всё равно заканчивается. При первом запуске программа пробует скачать ту же модель сама. Silero при установке не качается: пакет `v4_ru` (около 40 МБ) забирается с <https://models.silero.ai> при первом синтезе, код загрузчика — с GitHub `snakers4/silero-models`. Нужен интернет. Кеш в установленной копии лежит в `models\torch` рядом с программой.

Удаление через «Программы и компоненты» стирает модели (они тяжёлые) и не трогает `config.yaml`. Чтобы убрать и его, удалите папку программы после деинсталляции.

Запуск: ярлык или `RU-ATC.exe`. Рядом появятся `logs\`. Чёрного окна консоли нет, сообщения пишутся в лог и в окно диспетчера.

Дальше: [[Настройка|позывной и X-Plane]], затем [[Первый полёт|первый полёт]].

## Что лежит в папке

| Файл или папка | Зачем |
| --- | --- |
| `RU-ATC.exe` | программа |
| `config.yaml` | ваши настройки, создаёт установщик |
| `config.example.yaml` | образец, если захотите начать заново |
| `models\` | распакованная Vosk и позже кеш Silero |
| `data\` | аэропорты и секторы (примеры) |
| `THIRD_PARTY_LICENSES.md` | лицензии библиотек и моделей |
| `logs\` | журналы запусков |

## Повторная установка и смена голоса

Повторный запуск setup не затирает `config.yaml`. Другую модель можно докачать мастером (если её папки ещё нет), но путь в config останется прежним, пока вы сами не поправите `voice.vosk_model_path` и `voice.silero_speaker`. Как это сделать — в [[Настройка|настройке]] и [[Модели речи|моделях]].

Установка из исходников, с Python, описана отдельно: [[Запуск из исходников]].
