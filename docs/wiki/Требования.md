# Требования

Программа рассчитана на Windows 10 или 11, 64-бит. Запускать её нужно в самой Windows, не из WSL: Web API X-Plane слушает только локальную сеть машины с симулятором, а WSL2 по умолчанию сидит в другой.

## X-Plane 12

Нужен X-Plane 12.1.1 или новее: с этой версии в симуляторе есть Web API.

* Порт по умолчанию — **8086**. Если X-Plane запущен с `--web_server_port=другой`, тот же номер пишется в `sim.webapi_port`.
* В *Settings → Network* не должно быть «Disable Incoming Traffic». Иначе все запросы получают 403.
* Datarefs появляются после загрузки полёта. До этого программа ждёт и переподключается сама.
* Окно поверх симулятора работает в оконном режиме и в полноэкранном режиме в окне (без рамки). В эксклюзивном полноэкранном режиме Windows его не покажет. Режим: *Settings → Graphics → Monitor configuration*.

Запасной канал, если Web API недоступен: UDP RREF, порт X-Plane 49000, ответ на наш порт 49010 (`sim.source: udp`). Для UDP в брандмауэре нужно разрешить программу.

## Zibo 737

Основной самолёт — Zibo 737-800. Программа читает его datarefs (ответчик, FMC, экран CDU) через Web API. Сам самолёт в установщик не входит, его ставит пользователь.

Без Zibo связь с симулятором по обычным datarefs `sim/...` остаётся, но импорт плана из FMC и часть проверок (режим ответчика Zibo) не работают.

## Микрофон и гарнитура

Нужен микрофон, лучше гарнитурный: тангента по умолчанию — Caps Lock, наушники — устройство вывода Windows.

* Разрешение Windows на микрофон, включая классические приложения. Установленная программа — классическое приложение, не приложение из Microsoft Store.
* Гарнитура с одним штекером на 4 контакта в отдельные гнёзда микрофона и наушников без разветвителя не передаёт микрофон. В ноутбуке комбинированное гнездо обычно подходит сразу.
* USB-гарнитура видна как отдельное устройство. Его имя можно вписать в `voice.input_device` и `voice.output_device`.

Проверка микрофона из исходников описана в [[Устранение неполадок|устранении неполадок]].

## Место на диске и память

Зависит от модели распознавания, см. [[Модели речи]].

* Лёгкая Vosk — около 45 МБ на диске и около 300 МБ памяти.
* Большая Vosk — около 1,8 ГБ на диске и несколько гигабайт памяти. На странице Vosk большие модели в общем случае требуют вплоть до 16 ГБ.
* Silero v4_ru — около 40 МБ, качается при первом запуске. Для неё в установленную программу уже входит PyTorch, отдельный Python не нужен.

Интернет нужен на время установки (Vosk) и на первый запуск (Silero). Дальше эфир идёт офлайн. Симулятор при этом должен быть запущен локально.
