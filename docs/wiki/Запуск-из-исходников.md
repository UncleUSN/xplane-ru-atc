# Запуск из исходников

Так запускают разработку и тесты. Игроку достаточно [[Установка|установщика]]: Python отдельно не нужен.

Нужен Windows и Python 3.11 или 3.12, 64-бит, с галочкой «Add python.exe to PATH» на установке с <https://www.python.org/downloads/>.

```powershell
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy config.example.yaml config.yaml
```

Torch для Silero ставится отдельно, CPU-сборкой:

```powershell
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install omegaconf
```

Модель Vosk установщик здесь не качает. Либо положите распакованный архив в `models\` (адреса в [[Модели речи|моделях речи]]), либо просто запустите программу: если в `voice.vosk_model_path` указана лёгкая или большая модель из каталога и папки ещё нет, она скачается с alphacephei.com. Silero скачается при первом синтезе.

```powershell
python -m ru_atc
python -m ru_atc --console
python -m ru_atc --demo
python -m ru_atc --source mock
python -m ru_atc --compact
python tools\fmcdump.py
python tools\mictest.py --list
```

Те же команды есть в `run_atc.bat` и `run_demo.bat`, им нужен уже созданный `.venv`.

Тесты:

```powershell
pip install -r requirements-dev.txt
python -m pytest -q
```

Номер версии меняется только в `ru_atc/__init__.py`. Как растёт номер — в `CONTRIBUTING.md` и в шапке `CHANGELOG.md`.
