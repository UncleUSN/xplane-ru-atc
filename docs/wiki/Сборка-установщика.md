# Сборка установщика

Готовый `RU-ATC-0.3.0-beta-setup.exe` в git не хранится. Его собирает Windows: локально или workflow GitHub Actions. Среда, в которой готовилась эта бета, была Linux, поэтому сам exe там не запускался и не проверялся. Скрипт, сценарий Inno Setup и workflow в репозитории лежат и на Linux прогоняются тестами (каталог моделей, радиокнопки, страница папки X-Plane, текст `config.yaml`).

## Что получается

Мастер Inno Setup. После выбора папки программы — страница «Папка X-Plane 12» (обзор каталога, автопоиск, проверка `Resources\default data`), затем страница «Модели речи»:

* группа радиокнопок Vosk (лёгкая 45 МБ или большая 1,8 ГБ), ровно один пункт, по умолчанию лёгкая;
* группа радиокнопок голоса Silero v4_ru (aidar, baya, kseniya, xenia, eugene), ровно один пункт, по умолчанию aidar.

Подписи кнопок и адреса архивов генерируются из `ru_atc/voice/catalog.py`, чтобы не разъехаться с программой. Выбранный вариант записывается в `config.yaml` (если файла ещё нет). Архив Vosk качается с alphacephei.com во время мастера. Silero v4_ru качается при первом запуске с models.silero.ai. Веса в setup не входят.

Версия в имени exe берётся из `ru_atc/__init__.py` (`__version__`), сейчас `0.3.0-beta`. В ресурсе Windows при этом числовая четвёрка `0.3.0.0`: строка с `-beta` туда не встаёт.

## Локально на Windows

Нужны Python 3.11 или 3.12 x64 и [Inno Setup 6.3 или новее](https://jrsoftware.org/isdl.php) (в мастере используются загрузка по HTTPS и `x64compatible`).

Из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File installer\build.ps1
```

Скрипт сам ставит зависимости из `requirements-build.txt` (включая CPU-сборку torch и PyInstaller), заново генерирует `installer\generated\`, собирает `dist\RU-ATC\RU-ATC.exe` и компилирует `dist\installer\RU-ATC-0.3.0-beta-setup.exe`.

Сборка тяжёлая: в exe входит PyTorch. На диске и в артефакте это гигабайты, не мегабайты. Если ISCC не находится, поставьте Inno Setup 6: скрипт ищет `ISCC.exe` в `Program Files`.

Чтобы увидеть ошибки старта exe, в `installer/ru_atc.spec` поставьте `console=True` и соберите снова. В обычной сборке консоли нет, журнал — в `logs\`.

Поменять список моделей: правьте `ru_atc/voice/catalog.py`, затем `python installer/render_catalog.py`. Тест `tests/test_release.py` проверяет, что сгенерированные файлы совпадают с каталогом. Не правьте `installer/generated\` руками.

## GitHub Actions

Файл `.github/workflows/installer.yml`. Запускается вручную (Actions → Windows installer → Run workflow) и при теге `v*`. Бегун `windows-latest`, Python 3.12, Inno Setup через Chocolatey, затем тот же `installer\build.ps1`. Готовый exe — артефакт `RU-ATC-setup`.

Обычные пуши гоняют только тесты: `.github/workflows/tests.yml`. Сборку установщика на каждый пуш не вешают: она долго качает torch.

Проверка на Linux и в CI тестов не заменяет запуск setup на Windows. После первой зелёной сборки workflow установщик стоит прогнать руками: обе радиокнопки Vosk, смена голоса, появление `config.yaml` и папки `models\<имя>\am`.
