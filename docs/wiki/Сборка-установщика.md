# Сборка установщика

Готовый `RU-ATC-0.3.3-beta-setup.exe` в git не хранится. Его собирает Windows: локально или workflow GitHub Actions. Скрипт сам проверяет, что `RU-ATC.exe` стартует (`--help`, затем `--smoke`: импорт torch, Vosk, загрузка DLL PortAudio без `Pa_Initialize`, портреты и файлы рядом с exe). `Pa_Initialize` на бегуне без звуковой карты не возвращается, поэтому полная инициализация микрофона в этой проверке не делается. `--smoke` может создать пустые `cache` и `models\torch` рядом с exe; перед компиляцией установщика скрипт их убирает. Мастер Inno Setup на настоящей машине с X-Plane этим не заменяется: страницы папки симулятора и моделей речи стоит прогнать руками. На Linux тесты проверяют каталог моделей, радиокнопки, страницу папки X-Plane и текст `config.yaml`.

## Что получается

Мастер Inno Setup. После выбора папки программы — страница «Папка X-Plane 12» (обзор каталога, автопоиск, проверка `Resources\default data`), затем страница «Модели речи»:

* группа радиокнопок Vosk (лёгкая 45 МБ или большая 1,8 ГБ), ровно один пункт, по умолчанию лёгкая;
* группа радиокнопок голоса Silero v4_ru (aidar, baya, kseniya, xenia, eugene), ровно один пункт, по умолчанию aidar.

Подписи кнопок и адреса архивов генерируются из `ru_atc/voice/catalog.py`, чтобы не разъехаться с программой. Выбранный вариант записывается в `config.yaml` (если файла ещё нет). Архив Vosk качается с alphacephei.com во время мастера. Silero v4_ru качается при первом запуске с models.silero.ai. Веса в setup не входят.

Версия в имени exe берётся из `ru_atc/__init__.py` (`__version__`), сейчас `0.3.3-beta`. В ресурсе Windows при этом числовая четвёрка `0.3.3.0`: строка с `-beta` туда не встаёт.

## Локально на Windows

Нужны Python 3.11 или 3.12 x64 и [Inno Setup 6.3 или новее](https://jrsoftware.org/isdl.php) (в мастере используются загрузка по HTTPS и `x64compatible`).

Из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File installer\build.ps1
```

Скрипт сам ставит зависимости из `requirements-build.txt` (включая CPU-сборку torch и PyInstaller), заново генерирует `installer\generated\`, собирает `dist\RU-ATC\RU-ATC.exe`, прогоняет `RU-ATC.exe --smoke` и компилирует `dist\installer\RU-ATC-0.3.3-beta-setup.exe`. Архив Vosk мастер качает в `{app}\models`, не во временный каталог Windows.

Корень репозитория считается от расположения файлов, а не от текущей папки. В `installer\build.ps1` это родитель `$PSScriptRoot` (каталог `installer\`). В `installer\ru_atc.spec` PyInstaller задаёт `SPECPATH` как каталог spec-файла, и корень — его родитель (`installer\layout.py`). В `installer\ru-atc.iss` пути `..\dist\...` тоже идут от каталога `installer\`: один `..` — корень, туда пишется `dist\installer\RU-ATC-<версия>-setup.exe` и оттуда берётся `dist\RU-ATC`. Лишний уровень вверх на бегуне GitHub искал `D:\a\xplane-ru-atc\ru_atc\__main__.py` вместо файла внутри репозитория.

`sounddevice` — модуль, не пакет. PortAudio берётся из пакета `_sounddevice_data` (`portaudio-binaries\libportaudio64bit.dll`). Обход torch не заходит в `tensorboard` (его нет, он ещё и в `excludes`), `distributed` и `testing`: синтезу Silero они не нужны. Если другой модуль torch импортирует их сам, PyInstaller всё равно их подхватит.

Сборка тяжёлая: в exe входит PyTorch. Сжатый `setup.exe` с первого зелёного прогона CI — около 164 МБ. Распакованная папка программы больше. Если ISCC не находится, поставьте Inno Setup 6: скрипт ищет `ISCC.exe` в `Program Files`.

Чтобы увидеть ошибки старта exe, в `installer/ru_atc.spec` поставьте `console=True` и соберите снова. В обычной сборке консоли нет, журнал — в `logs\`.

Поменять список моделей: правьте `ru_atc/voice/catalog.py`, затем `python installer/render_catalog.py`. Тест `tests/test_release.py` проверяет, что сгенерированные файлы совпадают с каталогом. Не правьте `installer/generated\` руками.

## GitHub Actions

Файл `.github/workflows/installer.yml`. Запускается вручную (Actions → Windows installer → Run workflow) и при теге `v*`. Бегун `windows-latest`, Python 3.12, Inno Setup через Chocolatey, затем тот же `installer\build.ps1`. Готовый exe — артефакт `RU-ATC-setup`. Скрипт не отдаёт артефакт, если PyInstaller не создал exe, `--smoke` не прошёл или Inno Setup не положил `dist\installer\RU-ATC-<версия>-setup.exe`.

Обычные пуши гоняют только тесты: `.github/workflows/tests.yml`. Сборку установщика на каждый пуш не вешают: она долго качает torch.

Проверка `--help` и `--smoke` на бегуне не заменяет запуск мастера на Windows с X-Plane. После установки стоит прогнать руками: обе радиокнопки Vosk, смена голоса, появление `config.yaml` и папки `models\<имя>\am`.
