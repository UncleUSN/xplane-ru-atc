# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Номер версии берётся из одного места: `ru_atc/__init__.py`, переменная `__version__`.
Окно программы и установщик читают эту строку. В `pyproject.toml` она не дублируется:
`0.2b` не является версией PEP 440.

## Схема версий

Пока выпуск публичный и бета, в номере остаётся суффикс `b`.

Каждое следующее изменение помечается как **minor** или **major**:

* **minor** — исправление или совместимое добавление (фразеология, аэропорт в `data/`, окно, модель в каталоге установщика). Второе число увеличивается на 1: `0.2b` → `0.3b` → `0.4b`.
* **major** — несовместимое изменение: другой смысл ключей `config.yaml`, другая установка, смена протокола с X-Plane, из‑за которой старый config или сценарий запуска ломается. Первое число увеличивается на 1, второе становится 0: `0.2b` → `1.0b`.

Отдельного уровня «patch» нет: мелкий фикс тоже идёт как minor.
Снять бету (убрать `b`, например `1.0`) можно только отдельным решением владельца. Это не автоматический шаг major или minor.

## [0.2b] — 2026-11-23

Первая публичная бета. До неё публичных выпусков не было: разработка шла как внутренний MVP.

### Добавлено

* Внешняя программа на Python с окном tkinter: голосовой диспетчер на русском для X-Plane 12 и Zibo 737. Данные из симулятора по Web API (`localhost:8086`) и, запасным каналом, по UDP RREF.
* Фазы полёта от стоянки до прибытия, органы ОВД (Деливери, Руление, Старт, Вышка, Круг, Подход, Москва-Контроль, Санкт-Петербург Контроль), передачи между ними, разрешения и учебные проверки процедур.
* Импорт плана из FMC Zibo: datarefs `laminar/B738/fms` (маршрут `legs`, аэропорты, ВПП), экран CDU и файл `.fms` из `Output/FMS plans`. Позывной из номера рейса.
* По реальному дампу UUEE–ULLI маршрут берётся из `fms/legs`, SID — только со страницы с маркером `<SEL>` или `<ACT>`, а `fmc_gw_app` не читается как имя захода.
* Окно поверх X-Plane, компактная полупрозрачная панель и глобальные горячие клавиши показа и компактного режима.
* В компактной панели — последние 5 реплик обеих сторон.
* В полном окне — портрет диспетчера по полу голоса, которым говорит этот орган.
* Мягкая проверка readback (`atc.readback_strictness: lenient`): короткое подтверждение закрывает указание, неверное значение по-прежнему поправляется.
* Голос офлайн: распознавание Vosk, синтез Silero v4_ru (голоса aidar, baya, kseniya, xenia, eugene), радиоэффект, тангента с клавиатуры или джойстика.
* Установщик Windows: мастер с радиокнопками модели Vosk и голоса Silero. Выбранное пишется в `config.yaml`. Веса скачиваются с официальных адресов, в репозиторий не входят.

### Исправлено

* Разрешение на вылет больше не зацикливается, если пилот отвечает «подтверждаю приём» вместе с позывным («пятьсот первый»). Такое подтверждение закрывает указание, если в той же фразе нет противоречащего значения. Искажённые названия органов («шереметев», «делились») принимаются. Одну и ту же просьбу повторить диспетчер задаёт не больше двух раз, затем сам называет значения и идёт дальше.
